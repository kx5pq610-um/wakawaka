# サイエンス・クエスト Ver.20

基本語優先学習版

- 基本語 278語
- 発展語 37語
- 合計 315語

標準は「基本語中心」モードです。基本語習得率70%未満では基本語を優先し、70%以上になると発展語も少し混ぜます。画面の「全315語」ボタンで全範囲学習に切り替えられます。

## 学習機能

- 3回正解で習得
- 間違えた語は約5問後・10問後に再出題
- 習得後も約15問後に確認
- 苦手語を優先
- 315問品質チェック

## Apps Script への導入

1. `Code_ScienceQuest_V20.gs` を Apps Script の `Code.gs` に貼る
2. `science_quest_v20.html` を HTMLファイル `index` に貼る
3. 一問一答問題を自動生成
4. Webアプリとしてデプロイ

## Codex向け

このリポジトリをCodexで開き、以降の変更はこのVer.20を基準に行ってください。主目的は「中学校理科の用語を効率よく覚えること」です。RPG要素は学習を邪魔しない範囲に留めます。
